# Product decision: inventory change review

October 14, 2026

Choose small, self-serve retail operations software instead of custom diagnosis, freelance gigs or institutional tender screening. First release: a browser-only inventory CSV change reviewer. No store mutation, money handling, merchant credentials or external file processing.

The first piece is free. It is not a claim of demand, differentiation, customers or profit. The commercial model to test later is paid repeat-use tooling after operators actually use the reviewer and identify repeat work worth paying for. No recurring charge, paid app-store listing, checkout or promised support is enabled in v0.1.

The release does one bounded thing: compare planned on-hand changes against a fresh All states export, then produce a human-review exception report. Preserve the merchant's original files and Shopify's import validation. Do not generate an import file or silently repair bad input.

Evidence: official Shopify inventory CSV instructions establish exact headers and native stale-value protection. A public bulk-edit operator question is discovery evidence only, not a customer or authorization. No unique-market claim. Never infer somebody's geography from Shopify usage.

Next work stays on this product: real browser verification, documented examples, clear download/use route, then operator feedback through permitted product channels. No return to RFP rejection reporting.
