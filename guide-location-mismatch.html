Your location edit didn't take: check names, rows and "not stocked".

Open the free Inventory change review

In the inventory CSV, a location is part of each row's identity and names are case sensitive. A near-miss location name can leave your edit pointing at nothing, and "not stocked" has a specific meaning.

You edited an inventory CSV to move stock from one location to another, imported it without errors, and the locations didn't change. Before trying a third import, verify exactly what your file says about each location.

Verify the location side of the file

  1. Copy location names exactly from the admin. Shopify's inventory CSV documentation says the Location value is case sensitive and must match your Shopify location name exactly. Check spelling, capitalization, spacing and punctuation against Settings > Locations. Warehouse and warehouse are not the same location.
  2. Use the right row per location. Shopify says to include a row for each location where you want to update inventory for that variant, and to remove any other location rows. A variant's identity includes its handle, option values and the exact-case location; the same variant at two locations is two rows, not one.
  3. Use "not stocked" only for never-stocked. Shopify's docs say to use not stocked for products never stocked at that location, and quantities must be whole numbers (positive, negative or 0). Don't use not stocked as a generic "zero this location out" instruction without checking what it means for your setup; review Shopify's example scenarios first.
  4. Keep the safety check unless you truly must skip it. With All states files, Shopify compares On hand (current) with live levels and skips rows that changed since export. Shopify warns that clearing On hand (current) to skip validation removes protection against accidental overwrites. If your earlier import "did nothing," stale-validation skips are one possible explanation; check the import result email before clearing anything.
  5. Review the edited file before importing. The free Vertex Inventory change review compares a fresh All states export with your edited copy in your browser. It treats exact-case locations as distinct, flags a new location or a not-stocked baseline for manual review, and stops on duplicate identities rather than guessing. That makes a mistyped location name visible before it reaches your store. It cannot add locations, rename them, or import the file.
  6. Consider the native route for simple moves. For straightforward per-product edits, Shopify's admin (including its bulk editor) may avoid a CSV round trip entirely. The operator whose thread prompted this guide succeeded with the bulk editor after CSV attempts failed. Use CSV when you need it, not by default.
