Scope, privacy and limits

Version 0.3 supports UTF-8, comma-separated Shopify All states inventory CSVs with Handle, Location, Option1 Value (or Option 1 Value), On hand (current) and On hand (new). Available-only exports are not supported. Selecting a product catalog export or an Available-only export stops the review with a message naming the file type and the export steps that fix it. Filters affect the screen only; the full-review CSV always contains every compared instruction. Search matches handle and option values without changing the files. Optional second and third option values form part of the identity. SKU alone is never used as the join key.

Blank new quantities mean no quantity change. Whole numbers, including negative values, are accepted. A new location or a baseline marked not stocked requires manual review. Duplicate identities and missing variant fields stop comparison; they are never guessed or merged. Locations are case sensitive. The tool cannot see store changes after your fresh export, permissions, inventory policies or Shopify's final validation.

Only choose inventory exports. Do not use customer, order, payment, credential or production-log files. No selected file is sent to Vertex. The downloaded report contains inventory identifiers and counts; keep it private. Refreshing or clearing removes this page's in-memory results. The hosting provider may log the page visit, not the selected file contents. No automatic storage is used.

Vertex builds small, review-only operations tools for online retailers. This is a free first release, not a paid service offer. No customer cases or revenue claimed. Independent of Shopify, not an official Shopify app.

Format checked against Shopify's inventory CSV guide on October 14, 2026. Source and issue reporting are available in the repository. Never put private inventory files in public issues.
