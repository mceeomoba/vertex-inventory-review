Scope and privacy

Supports UTF-8, comma-separated Shopify All states files with Handle, Location, Option1 Value (or Option 1 Value) and On hand (current). Optional second and third option values are part of row identity. SKU alone is not an identity. On hand (new) is ignored; this tool compares current values, not edit instructions.

Duplicate identities, malformed CSV and missing required fields stop comparison. Exact-case locations are distinct. Not-stocked and invalid current values require manual review. Each file must be 15 MB or smaller. The screen shows up to 200 matching rows; the full review CSV contains all compared identities, regardless of filters. Added/missing refers only to export membership. No automatic alert or background store monitoring is provided.

Files are read in this browser, not uploaded. No external script, analytics or automatic storage. The host may log page visits. Clear or refresh removes in-memory results. Keep inventory exports and review downloads private; never use customer, payment or credential files.
