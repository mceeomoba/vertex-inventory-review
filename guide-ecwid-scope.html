How to check what an Ecwid CSV import will leave out.

For store operators preparing a catalog update by CSV import in Ecwid. Ecwid's import can replace more than the rows you edited: importing variation data deletes that product's variations that are not in the file.

Open the free Ecwid Import Scope Check

A fictional example

A shirt has Size S, M and L, and your import file has only S and L. After the import, M is gone, even if you only meant to change a price.

The fictional example is built in.
Open the tool and click "Try a fictional example" to see the same kind of result without using your own files.

Run the scope check

  1. Export your full current catalog from the same store (products, options and variations).
  2. Prepare the CSV you plan to import (current comma-separated format, not legacy).
  3. Open the tool, pick both files, tick the box confirming the export is fresh and complete, and click Review omitted rows.
  4. Read each omitted row and decide if it is intentional. Keep an untouched copy of the export.

Privacy and limits

Your files are read in this browser. No login, no store connection. Nothing is uploaded.

It is a review aid, not import approval. It checks omitted options, input fields and variations only, not prices, stock or images.

Vertex builds small, review-only operations tools for online retailers. This is a free tool, not a paid service offer. No customer cases or revenue claimed. Independent of Shopify, Ecwid and Lightspeed.
