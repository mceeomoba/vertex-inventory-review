Prepare your real review

  1. In Shopify admin, go to Products > Inventory and export inventory using All states. Use the product variants and locations needed for your update.
  2. Keep the exported original. In a copy, edit On hand (new). Keep On hand (current) in the file. A blank new quantity is skipped; zero is an explicit quantity instruction.
  3. Immediately before your review, make another fresh All states export covering the same variants and locations. Select that fresh export as the baseline and your edited copy as the edited file.
  4. Read each exception. If the snapshot is stale, re-export and reconsider the intended quantity. Do not simply replace the old snapshot value to bypass the warning.
  5. Use Shopify's own import preview and validation before making changes. The Vertex review report is not an import file.

Read the result

PLANNED_CHANGE
The edited snapshot matches the fresh file and the new whole-number quantity differs. Delta is new minus snapshot, not a store update.
UNCHANGED
The explicit new quantity equals the snapshot.
STALE_SNAPSHOT
The edited snapshot does not match the fresh export. Review the edit against current stock.
IDENTITY_NOT_IN_BASELINE
The handle, option values and exact-case location were not found together in the fresh file. Check export scope and identity fields.
INVALID_NEW_QUANTITY
The new value is not a supported safe whole number. Decimals and scientific notation are not accepted.
Manual review / range error
Not-stocked values, invalid current quantities or a delta outside safe numeric range need manual review. The tool does not guess.

Duplicate identities, malformed CSVs and missing required fields stop comparison. The on-screen list shows up to 200 instructions; the downloaded review contains all compared instructions.

Scope and privacy

This version reads UTF-8, comma-separated All states files with Handle, Location, Option1 Value (or Option 1 Value), On hand (current) and On hand (new). Option values and location identify rows, never SKU alone. Available-only exports are not supported.

Selected files stay in your browser. The app has no upload endpoint, external script, analytics or automatic storage. Its host may log page visits. Keep inventory files and downloaded reports private. Never put customer, payment or credential files in the reviewer or public issues.

The tool cannot see changes after the fresh export. It does not check inventory policies, permissions or Shopify's full import rules. Shopify already provides stale-value protection; this is a separate, human-readable review aid, not a replacement or an official Shopify app.
