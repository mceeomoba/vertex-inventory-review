A preflight, not an import approval.

Shopify's preview and import rules still decide what can be imported. Blank columns can overwrite existing values. Changing option values can replace variant IDs. This tool checks a limited set of fields and never automatically fixes or deletes a row.

Checks, scope and privacy

UTF-8, comma-separated CSV, up to 15 MB. Title is required. Update review also requires URL handle. Supports current Shopify headers and common legacy aliases: Handle, Variant SKU, Variant Price, Variant Compare At Price, Variant Barcode, Variant Grams, Published and Option1 Name/Value.

Checks packed-size field completeness, cm/in units and blank/non-shipping clearing risks. Does not validate dimensional ranges or actual shipping settings. Checks first-row titles by handle; continuation and image rows may leave title blank. Flags variant-related headers without Option1 name/value, nonstandard price/status/published values, repeated variant identities and reused SKUs. Repeated variants or SKUs can be intentional and are review notes, not automatic rejection. Create mode without handles treats each row as a separate new product; assign handles and recheck if your file contains variants or image continuations.

No check of images, linked metafields, market pricing, tax/shipping rules, actual store records, third-party dependencies or every Shopify field. A clean report does not prove a valid or safe import. Findings reference parsed CSV record numbers, which can differ from physical line numbers for multiline fields.

No file upload, external script, tracking or automatic storage. The host may log page visits. Clear or refresh removes in-memory results. Reports include identifiers: keep them private. Never use customer, order, payment or credential files. Never attach private files to public issues.
