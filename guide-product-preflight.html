Vertex / Product CSV Preflight / Quick start

A quick check of a Shopify product CSV before you import it.

For store operators preparing a weekly catalog update. This free browser tool flags price formats, reused SKUs, handles with spaces and invalid status values before the file reaches your store.

Run the preflight

  1. Open the tool and choose your Shopify product CSV.
  2. Pick whether you are updating existing products or creating new ones.
  3. Click Check CSV and read the findings. A REVIEW item is a prompt to look, not proof of an error.
  4. Fix the file yourself in your spreadsheet. The tool never changes it.

Privacy and limits

Your file stays in this browser. Nothing is uploaded.

Limited preflight, not import approval. Shopify's own import preview still decides what imports.
