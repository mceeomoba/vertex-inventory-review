What this checks

For straightforward catalog edits, Ecwid's native Bulk Product Editor may let you avoid CSV import entirely. This tool is for reviewing an import you already need to make.

  • If a planned import has variation rows for a product, it lists baseline variations absent from that product's planned rows.
  • If it has option or input-field rows, it also lists baseline options, input fields and variations absent from the planned replacement set.
  • Products with only product-level edits do not trigger these replacement checks. Products absent from the import are not marked as deleted.

Matching uses exact product IDs or unique product SKUs, then option names, types and values or variation option combinations. It does not match by product name. Conflicting identities and unsupported records are flagged for manual review.

An incomplete baseline can hide omissions. A changed option name or type can appear as an omission even if intentional. New products, changed parent SKUs/IDs, translated option headers and other ambiguous mappings need manual review. Maximum 10 MB per file.
