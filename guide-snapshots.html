Vertex / Snapshot comparison / Guide

Compare inventory exports without mistaking a difference for a cause.

Open the free Snapshot comparison

You want to review inventory changes across many variants without opening each product first. Two exports can help you narrow the list. They cannot tell you who changed stock or whether a difference was a sale, loss or mistake.

Start with the question you need answered

If you need the reason for an adjustment, check Shopify's own inventory adjustment history and Inventory adjustment changes report. Current Shopify documentation describes activity, staff/app attribution and adjustment reasons. A snapshot comparison is a separate view of quantities at two points, not a replacement for that history.

Compare like with like

  1. Keep an earlier export. Save an untouched All states inventory CSV from the store. Note when you exported it and which locations and variants you included. If you do not have an earlier file, this tool cannot reconstruct the past from a current export.
  2. Export the later snapshot with matching scope. In Shopify, go to Products > Inventory > Export. Choose the same locations and variant selection as before, and select All states. Use All variants if you intend a full-store comparison. A Current page or selected-variant export is not automatically comparable with a full export.
  3. Open the free Vertex Snapshot comparison. You can first try its fictional snapshots without store data. For your own review, put the earlier file in Earlier All states export and the later file in Later All states export, then select Compare snapshots.
  4. Read quantity changes as differences, not explanations. The tool compares On hand (current), ignoring On hand (new). Shopify defines on-hand inventory as the sum of Committed, Unavailable and Available. Do not read an on-hand difference as available stock or a count of sales.
  5. Investigate added and missing rows before acting. These labels describe membership in the two exports. A missing row might reflect a changed export selection, location name, handle or option identity. It does not prove that a product was deleted.
  6. Check identities and exceptions. Matching uses handle, option values and exact-case location, not SKU alone. Duplicate identities, malformed CSV or missing required fields stop comparison. Not-stocked and invalid quantities need manual review. Do not force a match by casually renaming identities.
  7. Use the full report when needed. The screen shows up to 200 matching rows; the downloaded CSV contains all compared identities regardless of filters. Keep the exports and report private. Check individual discrepancies against Shopify's own history before deciding on any stock correction.
Fictional example: A variant's on-hand quantity is 20 in the earlier export and 17 in the later one. The difference is -3. That alone does not establish three sales, theft, a count correction or which person or app acted. It also cannot show offsetting changes between snapshots.

What this review cannot do

It does not connect to your store, run in the background, send alerts, recover deleted products or update inventory. Files are read in your browser, not uploaded. Refresh or Clear removes in-memory results; keep your own private copies if needed. The host may log page visits. Each file must be UTF-8 comma-separated CSV, 15 MB or smaller, with the tool's required All states fields. Available-only files are not supported.

Do not import the snapshot review report as an inventory update. It is a review output, not a corrected import file or approval to change stock.
